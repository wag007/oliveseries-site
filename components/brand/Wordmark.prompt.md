One-line: the brand name set as type — there is no drawn logo in the source, so the wordmark IS the mark.

```jsx
<Wordmark variant="bubble" size="xl">Olive</Wordmark>
<Wordmark variant="heavy" size="lg">Olive</Wordmark>
```

`bubble` (Rubik Bubbles, 199/182px) opens a page; `heavy` (Rubik Black, 182/112/46px) closes one.
